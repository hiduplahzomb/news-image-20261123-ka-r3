markets, and the Banten factory fire.

## How it works

`draw.py` (Pillow, run locally) renders `entry.png` (1024×1024).
`main.py` is standard library only: it copies the pre-rendered image to
`$MAKEFUN_OUTPUT_DIR/entry.png`, byte-identical on every run.
